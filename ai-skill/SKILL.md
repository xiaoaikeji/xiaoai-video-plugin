# 小艾视频播放插件集成

小艾视频播放插件是一款微信小程序第三方视频播放插件，能够解决小程序内的视频播放资质问题。 接入插件后，小程序无须额外资质(服务类目)就可以播放视频。

本Skill旨在帮助AI在Coding场景中，自动将小艾视频播放插件接入微信小程序项目，并给出能直接落到现有代码结构中的修改。先识别项目技术栈和配置文件，再只加载当前任务需要的参考资料。

## 按任务读取参考资料

接入前请先访问 [小艾视频播放插件官网](https://weixin.xiaoaikeji.net)  获取试用或正式token、插件版本和联系方式。

## 按任务读取参考资料

- 首次接入、迁移原生 `video`、生成配置或示例代码：读取 references/integration.md。
- 查询属性、事件、实例方法或生成播放器封装：读取 references/component-api.md。
- 播放失败、黑屏、token 报错、真机异常或格式兼容问题：读取 references/troubleshooting.md。

## 工作约束

1. 先检查项目中的 `app.json`、页面 `.json`、`manifest.json`、`pages.json`、Taro 配置和已有组件封装，确定原生、uni-app 或 Taro/React 路径。不要同时输出多套实现，除非用户要求比较。
2. 将插件 provider 固定为 `wxd4709e80d42cb833`。它是插件 APPID，不是客户小程序 APPID；客户 APPID 仍放在项目自身配置中。
3. token 是按客户授权的凭据。使用变量或占位符接入，不要编造、提交、输出或把真实 token 写进公开仓库；缺少 token 时说明需要向插件服务方获取。
4. 修改 JSON 时输出合法 JSON，不能复制官网示例中的行内注释。合并现有 `plugins` 和 `usingComponents`，不要覆盖无关配置。
5. 播放器外层必须有明确高度；视频 URL 含中文或非英文字符时，在赋给 `src` 前调用 `encodeURI`；所有视频域名必须加入微信小程序服务器域名白名单。
6. 对不在本 Skill 参考资料中的原生 `video` 属性、事件或平台限制，查阅微信官方 `video` 组件文档，不要猜测。涉及当前价格、试用、token、插件版本或联系方式时，以官网实时信息为准。

## 完成标准

- 配置声明、组件注册和页面用法与项目技术栈一致。
- provider、组件路径 `plugin://m-video/m-video` 和 selector/id 前后一致。
- 布尔属性使用对应框架的动态绑定方式，而不是误传字符串。
- 给出最小验证路径：编译无配置错误、开发者工具能播放、真机非调试模式能播放、事件/方法按需验证。
- 若修改了项目文件，运行现有的格式检查、类型检查或构建命令；无法运行时明确说明未验证项。
